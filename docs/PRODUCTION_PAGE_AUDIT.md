## Project detected (summary)

- **Application type:** Hosted multi-tenant SaaS — Instagram/Facebook comment-to-DM automation console plus an in-browser Creator Studio (script writer, video tools). Public marketing homepage + signed-in console.
- **Technology stack:** Next.js 15 (App Router, React 19), TypeScript, Tailwind CSS v4, Supabase (Postgres + Auth, `@supabase/ssr`), TanStack Query, Zustand, Motion, Recharts, Phosphor icons, Zod. Deployed on Vercel (`vercel.json` cron: `/api/cron/process-jobs` daily 03:00). Cloudflare OpenNext config also present (`open-next.config.ts`, `wrangler.jsonc`).
- **Authentication model:** Supabase Auth. Email + password and Google OAuth (`src/components/auth/LoginForm.tsx`, `src/app/auth/callback/route.ts`). Public signup is flag-gated (`PUBLIC_SIGNUP_ENABLED`, default off — invite-only posture, `src/lib/billing/flags.ts`, `src/lib/signupProtection.ts`). Password recovery via Supabase `resetPasswordForEmail` → `/reset-password`. API auth is a verified Supabase JWT (Bearer or session cookie, `src/lib/auth.ts`); middleware protects `/dashboard /automations /analytics /contacts /billing /settings /script-writer /studio /setup` (`src/middleware.ts`). Roles: workspace owner / member / viewer (`src/lib/billing/*`, migration `20260730000030_workspace_role_viewer.sql`); platform admin gated by `ADMIN_EMAILS` (`src/lib/admin/panel.ts`).
- **Payment/business model:** Monthly-only plans, geo currency (INR in India, USD elsewhere, never both — `src/lib/billing/geo.ts`). Catalogue (`src/lib/billing/catalogue.ts`, owner-approved 2026-11-08): Free ₹0, Starter ₹299/mo, Growth ₹500/mo, Pro ₹799/mo, Enterprise custom (contact-led). **Payments are one-time orders with NO autopay** (`src/lib/billing/lifecycle.ts` — a paid period simply lapses at `current_period_end` unless a renewal payment is made). Gateway: Cashfree primary, Razorpay fallback (`src/lib/billing/cashfreeLiveProvider.ts`, `src/lib/billing/providers/*`). Activation only via signed provider webhook (`src/app/api/billing/webhook/route.ts`); the billing panel polls `/api/billing/status` and never claims activation itself. 15-day free trial, no card.
- **Data-sensitive features:** Meta OAuth tokens (AES-256-GCM encrypted at rest, per `src/app/privacy-policy/page.tsx` §2B/§4 and `src/lib/crypto.ts`), Instagram/Facebook webhook payloads (comments, DMs, story replies), audience contacts (500 in production), delivery logs, file uploads (card images, storage policies), AI drafting via Cloudflare Workers AI **drafting-only** (`src/lib/ai/workersAi.ts` — runtime AI replies deliberately NOT restored).
- **Design constraints (standing, verified in code):** full dark only (`forcedTheme="dark"` in `src/components/providers/Providers.tsx`); English-only UI; no self-hosted/open-source/GitHub/MIT wording user-visible; Plus Jakarta Sans + Instrument Serif (no Inter/Geist); Phosphor icons (no Lucide); reduced-motion honoured (`MotionConfig reducedMotion="user"`).
